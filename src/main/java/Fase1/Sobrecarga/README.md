# Etapa 4 — Sobrecarga

`Calculadora` possui três métodos `somar()` com parâmetros diferentes: dois inteiros, dois decimais e três inteiros.

`Validador` possui três versões de `validar()`, e `Fase1.Main` possui duas versões de `exibirResumo()`.

O Java escolhe a sobrecarga pelos tipos, quantidade ou ordem dos parâmetros. O tipo de retorno sozinho não diferencia métodos.
