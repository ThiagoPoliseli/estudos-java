# Fase 1 — Orientação a Objetos

Os temas estão separados em pacotes:

- `Fase1.Heranca`: `Animal`, `Cachorro`, `Gato` e `MainHeranca`.
- `Fase1.Abstracao`: `Funcionario`, `Gerente`, `Vendedor` e `MainAbstracao`.
- `Fase1.Interface`: interfaces, `Produto` e `MainInterface`.
- `Fase1.Sobrecarga`: `Calculadora`, `Validador` e `MainSobrecarga`.
- `Fase1.Sobrescricao`: `MainSobrescricao` usando métodos sobrescritos com `@Override`.
